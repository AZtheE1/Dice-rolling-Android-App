# Dice-rolling-Android-App

A modern, animated Dice Rolling Game built with Flutter.

## Features
- Procedural 3D animated dice with realistic rotation, scale, and tactile lighting effects.
- Single Player Mode (vs AI) & Multiplayer Mode (2-4 players) with customizable goal score.
- Profile Screen with Google Sign-In (`firebase_auth`).
- Dark mode gaming UI built with Google Fonts & `flutter_animate`.
- Winner celebration screen with dynamic confetti effects.

## Getting Started
1. Run `flutter pub get` to install dependencies.
2. Run `flutter run` on an Android emulator or connected device.
